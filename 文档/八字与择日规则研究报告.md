# 八字与择日规则研究报告（第一阶段，待人工审核）

研究日期：2026-09-25。本文是后续开发的规则审计，不是命理结论，也不改变现有日历。**“书中有此说”与“软件应自动判定”分开记录**；尚未核实的个人择日惯例不冒充《协纪辨方书》原文。

## 一、结论摘要

- 八字第一版宜做**可解释的四柱资料、十神、月令、藏干、通根、透干、旺衰证据和正格候选**。先显示证据及疑点，再由人判断。不要自动宣称唯一格局、唯一喜用神，也不要自动定从格、化气格。
- 择日第一版宜按**事项公共日课 → 当事人关系 → 婚姻双方分别核对 → 时辰**四层展示。公共日课有较明确的《钦定协纪辨方书》卷十一依据；个人八字和双人八字的“硬排除”尚缺同等可靠、统一的古籍依据，第一版应标为提醒或待审，不擅自设为绝对禁忌。
- **订婚/纳采与嫁娶必须分开**。《协纪辨方书》卷十一分别列“结婚姻”“纳采问名”“嫁娶”，宜忌并不完全相同。开业宜核“开市”，签约宜核“立券交易”，搬家宜核“移徙”；现代词与古代用事的映射仍须人工确认。
- 不在界面显示“92 分”一类看似精确的数字。内部若需排序，先排除已核实的事项禁忌，再比较重要条件和辅助条件，并逐条写明理由。宜忌相撞而缺制化依据时保留“待核”。
- 在本次查阅的八个代码库/分支中，**三个值得重点对照**：`zhiji-bazi` 的分层格局证据、`xuziping-bazi` 的候选与三种用神口径、`cnlunar` 的用事表与宜忌处理。它们都不能替代本项目的历法入口或直接成为正式个人择日标准。
- 需要用户拍板的关键是：第一版是否只给“格局候选”；个人冲克是否先作提醒；订婚、搬家、签约采用哪种古今事项映射；无法给出古籍原条的婚配偏重法是否暂缓。

## 二、现有系统已经有什么

系统正式入口是 `src/历法/index.ts` 的 `计算历法`；出生时间由 `src/生辰八字.ts` 调用 `计算最终时间` 后再进入它。项目已能显示公历转农历、节气、四柱，以及十二值星、黄黑道、日宜忌、时辰吉凶、神煞、冲煞和多种传统禁日。规则主要存放在 `配置/*.txt`，以中文条件表达。

| 已锁定事实 | 仓库核查结果 |
| --- | --- |
| 年、月、日 | `src/历法/干支.ts`：立春**具体交节时刻**换年；十二“节”划节气月；五虎遁起月干；日柱按 00:00 换日。23:00—23:59 夜子取当天日干，00:00—00:59 早子取新日干。 |
| 时辰、时间依据 | `src/历法/真太阳时.ts`：五鼠遁起时干；北京时间与真太阳时分列。真太阳时 = 北京时间 + `(经度－120°)×4 分钟` + NOAA 近似均时差。跨日后用**最终时间**重算日期和四柱。 |
| 黄历 | `src/历法/值星.ts` 按节气月支和日支定十二值星；`日吉凶.ts`、`每日宜忌.ts` 和时辰规则消费本项目结果及中文配置。日宜忌冲突时保守留空。 |
| 第三方依赖 | `lunar-typescript@1.8.6` 仍提供农历转换和节气时刻表（`农历.ts`、`节气.ts`）；四柱边界、干支推算、真太阳时、值星及大部分黄历规则为项目自主代码/配置。第三方库并未退出历法事实链，因此后续仍只能通过项目正式入口消费其结果。 |

`计算日期详情`以当天 12:00 展示日期级详情；**择时不能拿中午快照代替具体时刻**。后续任何候选日与候选时都要用同一条 `计算最终时间 → 计算历法` 路径。此为现有程序约束，不能因其他仓库采用 23:00 换日而改变。

## 四、八字格局规则：按人能复核的顺序

**月令 → 藏干与透干 → 通根与全局生扶克泄 → 旺衰倾向 → 正格候选 → 成败救应 → 调候另列。** 这条顺序是审阅流程，不能理解为单一古籍给出的公式。

1. **先看月令。**《[三命通会·卷五“论正官”](https://zh.wikisource.org/wiki/三命通會/卷五)》说正官先看月令；《[三命通会·卷十](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷10)》明确先看月支有无财官。《子平真诠》“论用神”以月令为取格枢纽。月令是节气月，不是农历月。
2. **看月支藏什么、是否透出。**地支藏干是格局候选的来源之一；月令本气与所透之神、是否清纯，均需列证。《三命通会》卷五“论正官”举“支藏干透”并列混杂、冲破等坏格条件。不要“见一个官字”便定官格。
3. **看日主有根、有助、有制。**“得令”看季节；“得地”看本气、中气、余气中的同类根及根是否被冲合；“得势”看天干和其余地支的生扶。根气和透干能改变失令/得令的初步印象。《[滴天髓·衰旺](https://zh.wikisource.org/wiki/滴天髓/12)》与《[滴天髓阐微](https://zh.wikisource.org/wiki/滴天髓闡微)》提供的是辨真旺衰的论法，不是固定百分比。旺衰只给**倾向和证据**。
4. **列正格候选并审破格。**优先审月令可取的财、官、印、食、杀、伤等候选，再查透干、混杂、冲合、制化、救应。建禄/月刃不能硬塞入普通月令十神：参《[三命通会·卷五“论建禄”](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷05)》及《子平真诠》“论建禄月劫”。从格须核日主是否真无可依之根与生扶、全局是否成一势，反向根/印比或破局关系如何处理；第一版只标“可能需人工复核”。化气格、从格不自动判成。
5. **把三种“用”分开。**《子平真诠》“用神”偏指月令立格及成败救应；扶抑是强弱平衡；《[穷通宝鉴](https://zh.wikisource.org/wiki/窮通寶鑑)》逐日干逐月讨论寒暖燥湿的调候，例如十一月甲木先谈寒气与丁、庚、丙的次序。三者可能不同，绝不能合成一个“喜用神”。第一版仅显示调候待核因素，不直接建议具体用神。

《[渊海子平](https://zh.wikisource.org/wiki/淵海子平)》的“论六亲”“论格局”展示早期日主、十神、月令及多种格名，可用来核术语，但内容层累、条目并存，不宜把整书当成单一决策算法。

## 五、古籍之间的主要分歧

| 问题 | 可核到的不同口径 | 本阶段建议 |
| --- | --- | --- |
| “用神”指什么 | 《子平真诠》“论用神”“论用神成败救应”偏月令格局枢纽；《穷通宝鉴》按日干与月份谈调候；《滴天髓》及任铁樵《阐微》重全局气势、生克流通。现代项目常统称“喜用神”。 | 分列**格局用、扶抑、调候**；不输出唯一用神。原书与注本分开标。 |
| 得令是否等于身旺 | 《三命通会》卷五重月令，但也要求日主健旺和其他扶助；《滴天髓·衰旺》重“真机”，不能只凭月份。 | 给得令、通根、透干和克泄的证据，不给“月令占 50%”公式。 |
| 建禄、月刃如何取格 | 《三命通会》卷五“论建禄”指出建禄须另看年时财官印食；《子平真诠》有“论建禄月劫”专章。 | 独立候选，不与普通正格机械同列。 |
| 从格与化气格 | 《滴天髓》有“从象”“化象”等论述；《子平真诠》以月令格局成败为主轴，两种文本的提问方式不同。开源项目把从格写成根数/比率阈值，阈值无古籍出处。 | 保留流派差异；第一版仅提示人工复核。 |
| 格局成败和身强弱 | 正官等格有“身旺”和财印、无伤杀等条件（《三命通会》卷五）；《子平真诠》还强调成败救应。身旺不是“格局好”的同义词。 | 两张判断卡分别显示。 |

《子平真诠》本次以可检索原本章节和“原本”影像目录作定位，**未完成逐页版本校勘**；因此涉及该书的细规则暂不作为自动规则。此处避免把现代评注误写成沈孝瞻原文。

## 六、择日规则：四层及证据强度

| 层 | 可用事实 | 硬排除 / 重要 / 辅助 |
| --- | --- | --- |
| 1. 公共日课 | 《[协纪辨方书·卷十一“用事”](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷11)》逐事项分宜、忌；项目 `配置/日宜忌.txt` 已有对应中文规则。 | **硬排除候选**：同一事项明确“忌”且无已核制化、与“宜”冲突时先不推荐；具体“忌”是否绝对、制化优先序仍需逐条核。**重要**：事项明确“宜”。辅助：黄黑道、值星等只能按各自规则解释，不能无差别叠加。 |
| 2. 单人八字 | 年支/日支与候选日的冲合刑害破、日干十神、命局喜忌、贵人等可**计算或列出关系**。目前未核到《协纪辨方书》卷十一把“冲本人年支/日支一律禁”写成通用条款。 | 第一版全部先作**重要提醒或辅助资料**；不能把冲一律硬排除，更不能把尚未定准的喜用神变成加减分。 |
| 3. 双人婚姻 | 对男女双方分别列候选日与年支、日支（夫妻宫）的关系；纳采和嫁娶先各查公共日课。 | 未核得通用、逐条可审的“女命优先/男命优先”及双方硬排除表。任何一方明显相冲可作醒目提醒；**不得暗设硬排除或性别优先**。若要使用某通书婚嫁法，应先确认版本、卷页和适用事项。 |
| 4. 择时 | 候选日确认后，以最终时间取本项目时柱、时辰吉凶、时宜忌、黄黑道，并列与当事人的冲合。 | 时辰本事项明确“忌”且无制化依据，可不推荐该时段；吉时、六合、贵人作排序理由。跨 23:00/00:00 必须重算日课，不可把夜子、早子视为一个固定日。 |

推荐展示：“某日某时；本事项日课命中××；男方/女方分别有××关系；该时段命中××；待核××。”不要只报数字。内部权重若要设计，须有版本号、规则出处、命中证据、冲突状态，并让“硬排除”先于排名；不得把神煞个数相加当数学概率。

## 七、事项分类与古今名称映射

| 现代事项 | 《协纪辨方书》卷十一相近用事 | 能共用什么 / 必须独立什么 |
| --- | --- | --- |
| 订婚 | “结婚姻”“纳采问名”是候选；现代订婚仪式未必等于古礼的纳采、问名。 | 共用历法和当事人关系计算；须单独映射、单独查用事。**不套嫁娶**。 |
| 结婚 | “嫁娶” | 共用历法；公共宜忌独立，夫妻双方关系分别说明。 |
| 搬家 | “移徙”（原文“般移〈移徙同〉”）；“安床”另列。书中未在卷十一把“入宅”作为同名独立条。 | 共用历法；是否含安床/入宅仪式由场景决定，不能自动并成一个词。 |
| 开业 | “开市” | 与立券、交易有不同宜忌；签合同、开门营业可能是两个事件。 |
| 签约 | “立券交易” | 先用立券作古义近似；纯现代电子签约映射须用户确认。 |
| 出行 | “出行” | 与移徙、远迴不同；不因外出即套搬家禁日。 |
| 祈福 | “祈福” | 若实为设醮、拜表、开光、塑像等道教科仪，另走科仪规则，不扩散到民用事项。 |

《[协纪辨方书·卷七](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷07)》可核黄黑道神的传统背景；《[卷三十五](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷35)》有彭祖百忌等条，不能因通用标签“宜嫁娶”就覆盖卷十一的事项表。择时与日课若出现相反信息，先列冲突，不用一个分数掩盖。

## 九、需要用户人工确认的问题

**问题 1：第一版格局给到哪一步？** 背景：月令、藏干、透干可客观列出，成格与从格有流派差异。方案 A：只给正格候选、证据和待核点；方案 B：自动给唯一格局。**建议 A**。影响：A 保留人工判断，B 需先完成版本校勘和判例集。

**问题 2：个人冲克作为硬排除吗？** 背景：开源项目常将冲年支/日支一律排除，但本次没有核到《协纪辨方书》卷十一的通用对应条。方案 A：醒目提示、参与人工排序；方案 B：特定事项直接排除。**建议 A**，直到确认原书卷页和事项条件。影响：候选日数量与解释方式。

**问题 3：现代事项映射怎么定？** 背景：卷十一把婚姻三类、开市与立券交易分开，“入宅”不在该卷同名用事中。方案 A：订婚默认“纳采问名”、搬家默认“移徙”、签约默认“立券交易”，并让用户改选仪式；方案 B：把相近用事合并。**建议 A**。影响：候选日结果会因映射不同而变。

**问题 4：双人婚姻的性别偏重法何时进入？** 背景：本次尚无可逐条复核的女命优先或男命优先原条。方案 A：双方对称展示，传统偏重法待来源校勘；方案 B：先套某一现代通书口径。**建议 A**。影响：第一版不给单一“婚配最吉”裁断。

## 十、第一版功能范围建议

**做：**复用正式历法入口；四柱/藏干/十神和月令证据；正格候选及可能破格的说明；独立的调候提示；按七类事项的公共日课筛查；单人和婚姻双方关系卡；日期确定后的时辰筛查；带来源、命中理由、冲突提示的推荐清单。

**暂缓：**唯一身强弱分数、唯一喜用神、自动定从格/化气格、没有原条的硬排除、女命或男命优先、把嫁娶套订婚、精确吉日分数、道教科仪规则混用、任何新历法核心或第三方在线服务。公共日课中当前项目尚未实现的神煞及制化，也不能假装已经计算。

## 十一、后续开发拆分（人工确认后）

1. **校勘与判例**：确认上述四个问题；给每条采用规则锁定版本、卷页和正反例，整理现有日宜忌冲突及制化。
2. **只读命盘解释**：消费现有四柱，生成可复核的十神、藏干、通根、格局候选，不改历法核心。
3. **公共事项择日**：七类事项映射及卷十一规则，逐条核制化，输出命中理由。
4. **单人、双人和择时**：先关系说明，再经审核转成排除/排序规则；核夜子、交节、真太阳时跨日案例。
5. **用户验收**：抽查书页、冲突例和跨边界例；确认界面措辞后再决定是否发布。
