# 古籍判例库（第四阶段影印核校中）

判例分“**命中事实**”“**卷十已明说的局部分支**”“**任意日期完整终判**”三级。只有第三层的全部必要神煞、逐月等第与专忌均覆盖时才可作全日自动测试；前两层也可立即作为单元/属性测试。以下公历日期均为**北京时间 UTC+8**，默认 12:00 取样；柱与节气界线使用本项目正式 `src/历法/index.ts` 的 `计算历法`、`获取指定节气`、`计算最终时间` 实测，未另写历法计算。原文依据：[《协纪辨方书》卷四](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷04)、[卷五](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷05)、[卷六](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷06)、[卷十](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷10)、[卷十一](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷11)。条目 ID 对应[起例表](./协纪辨方书神煞起例表.md)。

## 结论与缺口

当前已有正、反、冲突、逐月制化、时间界线的**可回归事实样本**，其中 D12—D16 可验证卷十明文分支，D22—D25 可验证卷九农历月日格。**尚无一例覆盖九项任一事项完整终判的全部命中神煞、等第、德、专忌与铺注**：卷九、十影印表全部组合、D17—D19 的具体日期、无禄/路空等补条与四柱格局古籍命例尚缺。应先补录并锁定这些基准，再开放完整自动裁断；用户无需为原书已明言的规则作人工决断。
