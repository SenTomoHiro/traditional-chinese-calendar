## 1. 资料的分工与输入契约

| 层 | 原书依据 | 软件应取得的事实 | 输出 |
| --- | --- | --- | --- |
| 历法事实 | 卷一至三“本原”，卷四“建除十二神” | 现有正式历法入口给出的年、节气月、日、时干支、节气交接时刻、农历日数和时区/真太阳时设定 | 不在规则层重算干支 |
| 神煞起例 | 卷四至八“义例”、卷九“立成” | 年干支、**节气月建**、日干支、必要的时干支；某些日数神另取农历月日 | 每个神煞命中与原书证据 |
| 事项原始宜忌 | 卷十一“用事” | 九项古籍事项之一 | 该事项宜神、忌神、专忌列表 |
| 轻重与例外 | 卷十“宜忌”“宜忌等第表”“铺注条例” | 全部命中神煞、月份、德合、事项 | 从宜、从忌、相抵、宜忌并见、仍忌或诸事皆忌 |
| 择时与私人条件 | 卷七、八、九时神；卷三十三至三十六仅在明确事项域内 | 时干支、事主输入及山向等 | 独立附加判定，不能代替日层结论 |

“月”默认以交节后的月建为准（卷四“建除十二神”明说“每月交节则叠两值日”）；`长星/短星`等“按月取日数”则保留农历月日输入，不能把两种月混为一个整数。立春前后年柱也只取正式历法结果。规则层保存时间依据与交节瞬间，不能把 23:00 子时、00:00 民用换日、真太阳时跨日擅自合并。

## 2. 状态模型与裁断次序

卷十一开篇说“选择由事起”，卷十“铺注条例”先依用事察宜忌、再按轻重定去取。因此每项必须留存两种结果：`原始命中`与`铺注结论`。原始命中可以是宜忌并见；它不是最终结论。`不注宜亦不注忌`也不是现代意义的中性吉日，而是卷十规定的相抵或联动结果。

1. 固定**古籍事项**与日期时区，取得正式历法事实；保留原始干支与节气界线。
2. 按卷四至九起例列出全部命中；同一位置的异名（如月破/大耗、成日/天喜、除日/吉期）记录一个事实、多个原书名称，不重复计数。
3. 按卷十一该事项分别列出宜与忌，并加入卷十的百忌日、无禄/上朔/四离/四绝/晦日/月忌日/二至二分等**事项特定**补充。若未完成神煞计算，应输出“资料未全”，不可当作没有命中。
4. 先查卷十对**具体神煞＋具体月/日**的明文处置，如建、破、平、收、满、闭及劫、灾、月煞、月刑、月害、月厌。其“从某煞论”“止忌……余皆不忌”“诸事皆忌”属于明确分支；不是从神煞数目推断。
5. 对卷十未被逐月特条直接定断的组合，依“宜忌等第表”所列组合归入六等，再按有无**该条允许的**德合等条件执行。从卷十序文看“德”不能无条件解一切凶。表格的每行匹配须附影印页与行列位置；未完成行列录校时不可用“最近等级”猜测。
6. 保留卷十“遇德犹忌”、百忌日及专忌。卷十明说吉足胜凶、相抵时若遇德犹忌仍注忌；`月破`与德合并仍有禁项，卯酉月又值灾煞月厌时仍诸事皆忌。`亥日忌嫁娶`、`申日忌安床`、`巳日忌出行`等不得被一个普通宜神抹去。
7. 最后执行卷十“铺注条例”的**有限联动**；输出“注宜/注忌/两者皆注/两者皆不注”及所有理由。联动只改变文书铺注，绝不把两事项视作同一规则。
8. 如需择时，另取卷七、九、三十四的时神与时忌；日时两层同时展示。卷三十三至三十六涉及造葬、方位、命主者只进入相应领域。

卷十图页 219—220 将「上朔、四离、四绝、晦日」同列，但其按语又明分晦日：**「余事虽不忌亦不注宜」**。因此在第 3 步中必须保留 `不注宜`、`注忌` 两个独立位；不能把晦日直接继承为上朔式的显式忌，也不能把“不忌”反推为宜。该条的最终注忌语境尚待与铺注逐句校定。

## 4. 铺注中与九项直接相关的规则

以下均出[卷十“铺注条例”](https://zh.wikisource.org/wiki/欽定協紀辨方書_(四庫全書本)/卷10)，应逐条形成可追溯的规则 ID：

| ID | 前提 | 动作 |
| --- | --- | --- |
| P01 | 吉足胜凶从宜不从忌，或相抵不注；该事项“遇德犹忌” | 仍注忌 |
| P02 | 德合、赦愿、月恩、四相、时德等日；非遇德犹忌且非从忌日 | 进人口、安床、经络、酝酿、开市、立券交易、纳财、开仓库、出货财不注忌 |
| P03 | 吉凶相抵而不注忌祈福 | 求嗣也不注忌；不代表注宜 |
| P04 | 相抵而不注忌结婚姻 | 冠带、纳采问名、嫁娶、进人口亦不注忌；遇德犹忌仍忌 |
| P05 | 相抵而不注忌嫁娶 | 冠带、结婚姻、纳采、进人口、般移、安床亦不注忌；遇德犹忌仍忌；不将和亥日/厌对/八专/四忌/四穷有本条限定 |
| P06 | 相抵而不注忌般移或安床 | 另一项亦不注忌；遇德犹忌仍忌 |
| P07 | 相抵而不注忌开市、纳财或立券交易 | 三项限定互相不注忌；开仓库、出货财的扩大条另要求排除专忌 |
| P08 | 巳日忌出行 | 不注宜出师、遣使；但不能反推巳日所有事项皆忌 |
| P09 | 卷十百忌日 | 申日忌安床、亥日忌嫁娶、巳日忌出行等各自独立 |

卷十有时写“从宜亦从忌”，有时在**铺注语境**写“吉凶相抵不注宜亦不注忌”。这两种不能合并：前者是轻重表的通则分支，后者是指定组合与事项在历书上的写法。实现必须保存来源分支与最终注记，而不是只给单一布尔值。
