# 八字与择日规则清单（研究草案，尚未批准入生产）

更新：2026-09-25。此清单是**待审核规则契约**，不是现行择日结果。状态：`基线`=仓库已实现；`候选`=有可复核出处但尚待人工/制化核对；`研究`=关系可计算、择日效力未证；`暂缓`=第一版不得自动裁断。优先级从 P0（历法事实）到 P3（辅助）。`硬排除`一栏的“候选”意味着还需逐条核书和用户批准。

后续统一输入约定：出生人与候选事项均使用 `计算最终时间 → 计算历法`；按事项使用**具体时刻**，不借用日期详情的 12:00 快照。若地点缺经度，明确以北京时间计算，不暗作真太阳时。所有规则输出同时带 `规则ID、命中条件、来源位置、是否冲突、是否人工复核`；不输出伪精确概率。

## 落地前必须补的出处和判例

1. 《子平真诠》选定底本、页码；区分沈氏正文与徐乐吾等后人评注。未校前 B06—B10 不自动下终局。
2. 《协纪辨方书》卷十一的完整宜忌等第、制化条与现有中文配置逐条核对。D02 的“单侧忌”不得被表面吉神覆盖；存在制化时按核得规则复核。
3. 《象吉通书》《鳌头通书》《玉匣记》选定版本、具体页及事项词义；未核到的双人婚姻法暂不进入硬排除。
4. 子时、交节、真太阳时跨日等判例只对照外部库，正式期望值永远以本项目 C01—C04 为准。

来源入口与书目限制详见[《八字与择日规则研究报告》](./八字与择日规则研究报告.md)第八章。
