# 传统历法日历系统

[English](README_EN.md)

> **Traditional Calendar Web Tool** — A browser-local calendar for the Chinese lunisolar calendar, the 24 solar terms, Ganzhi (Heavenly Stems and Earthly Branches), true solar time, and reviewable traditional date-selection rules.

一个面向中国传统历法、干支、节气、真太阳时与传统择日规则的 Web 日历工具。它把公历日期、农历日期、节气月与用于时辰计算的时间体系明确区分，并尽量让传统规则资料保持可读、可检查、可维护。

## 项目愿景

本项目希望借助 AI 技术降低专业软件开发的技术门槛，把传统历法知识转化为开放、可检查、可测试并能够持续维护的软件工具。项目长期希望服务道士、传统文化研究者与爱好者，以及其他有实际传统历法需求的人，让他们更容易获得透明且可持续改进的传统历法工具。

> 这是一个领域实践者主导、GPT / Codex 协助工程实现的开源传统历法项目。

## 项目缘起

本项目由一名没有正式软件工程背景的道士发起并持续维护。维护者负责传统历法知识、相关道教及传统资料研究、需求定义、传统规则判断、来源核对和最终验收；软件工程实现、代码修改、测试、调试、重构和持续迭代主要通过与 OpenAI GPT 和 Codex 协作完成。

维护者承担最终的产品与领域规则决策责任，不把 AI 当作传统规则的权威来源。项目也在探索：具备领域知识的实践者能否在 AI 协助下，持续建设和维护可审阅的开源软件。

## 为什么不是普通日历 Demo

普通日历通常只显示公历或农历日期。本项目将传统历法计算中容易混淆、又会影响结果的边界显式建模：例如以**立春的实际交节时刻**切换年柱、以十二“节”切换节气月、在 23:00 进入子时而日柱仍在 00:00 换日，并在定位可用时结合经度与均时差（Equation of Time）计算真太阳时。

传统择日资料也不被隐藏在不可审查的线上服务中：项目以中文自然语言配置文件维护可配置规则，并保留资料来源存在差异时的后续核对空间。

## 核心功能

- **公历与农历**：月历、农历日期、闰月、传统节日与神圣纪念日。
- **二十四节气 / 24 Solar Terms**：显示节气，并使用精确交节时刻处理立春换年与节气月边界。
- **干支 / Ganzhi**：计算年、月、日、时四柱（Heavenly Stems and Earthly Branches），并显示十二值星。
- **子时与时间边界**：23:00 进入子时，夜子与早子分别计算时干和值神；日柱在 00:00 更换。
- **北京时间与真太阳时**：默认以北京时间工作；取得浏览器定位后，以当地经度和均时差计算真太阳时。定位失败或被拒绝时安全回退到北京时间。
- **传统择日**：显示日吉凶、日宜忌、时辰值神、吉凶、神煞与部分风水禁忌速查；配置化的传统资料位于 [`配置/`](配置/)。
- **浏览器本地计算**：正式运行不依赖自建后端或账号系统；定位只用于当前计算，不建立位置历史。
- **响应式与主题**：适配电脑、iPad 与手机，支持浅色、深色和跟随系统主题。

> **Terminology note:** 农历（Chinese lunisolar calendar）与节气月（solar-term month）不是同一体系；本项目分别处理它们，避免将农历月份直接用于月柱计算。

## 设计原则

- 尽量在浏览器本地完成计算，减少服务器依赖。
- 保持实现直接、稳定、可维护，避免不必要的后端、数据库或复杂框架。
- 将可维护的传统规则写成可阅读的中文文本；配置错误会给出文件名、行号和原文，而不让网站崩溃。
- 逐步减少传统黄历结果对第三方黑箱数据的依赖；底层农历转换与节气时刻使用 `lunar-typescript`，项目自行实现并测试多个日、时规则。
- 对版本、古籍或资料来源存在差异的传统规则保留出处与待确认空间；结果不应被理解为“唯一权威”或适用于所有传承。

## 本地运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

## 测试与质量

```bash
npx playwright install webkit
npm test
npm run build
```

`npm test` 会运行历法与规则的自动回归测试，以及 WebKit 下多种窄屏宽度的响应式布局测试。`npm run build` 会执行 TypeScript 检查并生成生产构建。

## 规则、资料与依赖

- [`配置/`](配置/)：以 UTF-8 中文 TXT 文件维护传统节日、神圣纪念、时辰吉凶等可配置规则。
- [`资料来源说明.md`](资料来源说明.md) 与 [`资料/`](资料/)：记录部分规则及真太阳时资料的来源和核对工作。
- [`第三方资料/`](第三方资料/)：保留上游快照和来源说明。
- [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)：第三方软件声明。

正式运行不调用上游的节日或宜忌结果接口。日柱、四柱边界、十二值星、日吉凶、日宜忌、时辰值神与神煞由本项目独立实现并进行自动测试。
