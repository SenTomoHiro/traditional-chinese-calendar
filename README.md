# 传统历法日历系统

这是一个简单、稳定、容易维护的传统历法 Web 日历。当前已完成公历、农历、传统节日、神圣纪念、二十四节气、四柱、自主黄历、北斗规则、浏览器定位与真太阳时。

## 当前功能

- 完整公历月历，每个日期固定预留三条传统节日、神圣纪念或斗降摘要。
- 顶部使用单一 `YYYY/MM/DD` 日期按钮；点击后打开含日期、今天和清除操作的选择层，选回或清空为今天时恢复实时查询。
- 显示真实农历日期、闰月、节气、合并后的四柱和十二值星。
- 日期详情完整显示当天的传统节日与全部神圣纪念。
- 年柱按立春具体交节时刻换年，月柱与月建按十二“节”换月。
- 今天默认使用当前北京时间，其他日期默认使用北京时间 12:00，也可直接选择查询时间。
- 浏览器定位成功后按经度和均时差计算真太阳时；拒绝、超时或不可用时自动使用北京时间。
- 所有日期、时辰、日柱、时柱与现有时辰规则统一使用同一个最终计算时间。
- 23:00 进入子时，日柱仍在 00:00 换日；夜子与早子分别使用各自日柱计算时干和值神。
- 风水禁忌速查并入当前查看的具体时辰详情，可查询未来日期与未来时辰；十二时辰概览继续显示钟表范围、时干支、值神与吉凶。
- 十二时辰详情的值神、吉凶与神煞由项目中文配置和自主算法生成；丰富时宜与时忌来自已冻结的 `lunar-typescript` 1.8.6 本地快照，并明确标注“现代黄历宜忌体系”。
- 十二时辰标题可一键恢复当前查询时辰。
- 日吉凶与值日同处两列核心行，下方日宜与日忌沿用同样的两列节奏；节气、神圣纪念、传统节日常驻三列。
- 日吉凶下方显示自主日宜、日忌；月级规则按项目统一的节气具体交接时刻切换。
- 节气、神圣纪念、传统节日常驻显示，空值统一显示“无”。
- 北斗模块分开显示斗降日、本命下日、本命星官，并保留两种古籍来源的命中依据。
- 月历下方提供独立生辰八字查询，可按北京时间或手工经度真太阳时计算四柱。
- 节气、神圣纪念与传统节日使用紧凑三栏，时辰详情内的风水禁忌速查自动多列，手机端按宽度自适应。
- 自动适应手机、平板和电脑。
- 自动跟随系统浅色 / 深色模式。
- 自动读取 `配置/` 中全部中文 TXT 规则文件。
- 配置错误会记录文件名、行号和原文，不会导致网站崩溃。

## 本地运行

需要 Node.js 20.19 或更高版本。

```bash
npm install
npm run dev
```

执行自动测试和正式构建：

```bash
npx playwright install webkit
npm test
npm run build
```

`npm test` 会同时运行算法单元测试与 440、430、390、375、320px 的 WebKit 父卡片内容边界测试。

## 维护传统规则

传统规则仍然只维护在 `配置/` 目录的中文 TXT 文件中，不需要修改 JSON 或程序代码。编辑后重新构建网站即可生效。

## 历法依赖

底层农历转换和节气时刻采用 `lunar-typescript` 1.8.6。传统节日和现代时辰宜忌均已按该版本冻结为项目本地中文配置，正式运行不调用上游节日或宜忌结果接口。日柱、四柱边界、十二值星、日吉凶、日宜忌、时辰值神与神煞均由项目独立实现并测试。

## 资料与规则

- `开发规则.md`：项目的基础开发规则与算法边界。
- `GPT项目提示词.txt`：可直接放入 GPT 项目的长期提示词。
- `待确认规则.md`：目前存在冲突、缺项或需要后续确认的传统规则。
- `配置/`：全部采用中文文件名和中文自然语言格式，方便人工维护。

## 配置文件基本规则

1. 配置文件统一使用 UTF-8 编码。
2. `#` 开头的行是备注，程序应忽略。
3. 空行应忽略。
4. 中文冒号 `：` 为推荐格式，同时允许英文冒号 `:`。
5. 一条错误配置不得导致整个系统崩溃。
6. 配置错误时，应明确提示：文件名 + 行号 + 原始内容。
7. 不使用 JSON、数据库或复杂配置格式作为人工维护入口。
8. 配置文件是传统规则的主要数据源，底层历法算法仍写在程序代码中。

## 重要说明

- 公历、农历、二十四节气、四柱、真太阳时、十二值星属于底层算法；时辰值神与吉凶规则维护在 `配置/时辰吉凶.txt`。
- 农历月与节气月必须严格区分。
- 神圣纪念日支持农历单日、同日多事件、同月日期范围和“每月”重复规则，闰月默认不重复。
- 所有“时”规则统一使用系统最终得到的时辰；定位成功时优先用真太阳时，定位失败时使用北京时间。
- 北京时间与真太阳时都按自身钟点在 23:00 进入子时、00:00 更换日柱。
